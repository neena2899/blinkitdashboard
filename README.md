# Blinkit Grocery Sales — Power BI Dashboard

## Overview
A single-page Power BI dashboard analyzing grocery outlet performance —
sales, ratings, item mix, and outlet trends — with interactive filters
and slicers.


## Key Insights
- Item mix breakdown by Fat Content and Item Type
- Outlet performance by Location Type and Outlet Size
- Total Sales trend by Outlet Establishment Year

## Tools Used
Power BI, DAX, Data Visualization, Pivot Tables

## Files
- `Blinkit_Dashboard.pbix` — full Power BI file (open in Power BI Desktop)
- `Blinkit_Report.pdf` — static export for quick viewing without Power BI
